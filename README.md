# DATATYPE.PDFSchematic — Vector Schematic PDF Exporter

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery.

Vector Schematic PDF Exporter: compiles multi-page engineered schematics into vector PDF documents with ANSI/ISO architectural title blocks, revision history stamps, cover pages, and drawing notes.

| | |
|---|---|
| **Opens** | the OS shell (Pipeline → Translators & Formats), or `index.html` standalone |
| **Build** | none — plain web files; `npm test` |
| **Ships** | baked into WEB.Frontend-Assets (`up-stack.sh WEB.Frontend-Assets`), served at `:8080/Softapps/DATATYPE/DATATYPE.PDFSchematic/` |
